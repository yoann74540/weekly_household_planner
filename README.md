# Weekly Household Planner

A custom integration for Home Assistant to create and manage a weekly household task schedule.

## Features

- Weekly household task planning
- Custom actors
- Custom task types
- Custom parameters
- Native Home Assistant calendar
- Lovelace weekly planner card
- Add, edit, duplicate and delete scheduled tasks
- Home Assistant services for accessing and modifying the schedule

## Installation

### HACS

HACS installation instructions will be added when the repository is ready for distribution.

### Manual installation

Copy:

`custom_components/weekly_household_planner`

to:

`config/custom_components/weekly_household_planner`

Restart Home Assistant, then add **Weekly Household Planner** from:

**Settings → Devices & services → Add integration**
